#### 🚀 Featured projects
- **Conversational Analytics Agent Platform**: LLM copilot that answers natural-language questions over large-scale payments data. A routing agent hands work to analytics, investigation and business-intelligence agents with 50+ MCP tools, multi-tier RAG and an LLM-as-a-judge reviewer on every report.
- **Real-Time Voice AI Agent Platform**: streaming STT → LLM → TTS calls over Twilio/Exotel/Plivo, with a Redis dispatcher that clears 100k-lead backlogs at ~2.5k leads/s. Pre-warmed agent pools cut answer time from 8s to 3s.
- **FlowDesk**: messaging and workflow hub with email and chat in one place, SLAs, a trigger/step automation engine (10+ triggers, 25+ actions) and LLM email classification.
